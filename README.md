# Ростов-на-Дону, Нахичевань и Донская область: старые справочники

Адресные книги и справочники Ростова-на-Дону, Нахичевани-на-Дону и Донской области за 1912–1928 годы. Поиск по фамилиям, адресам, учреждениям, предприятиям и объявлениям. Распознанный текст можно читать на сайте и скачивать.

**[Открыть сайт](https://dennech.github.io/rostov-books/)**

## Как распознавали

Основное распознавание выполнено моделью Google Gemini 3.8 Flash через OpenRouter в режиме Flex. Модель читала изображения страниц, включая объявления, таблицы и мелкий шрифт.

В инструкции требовалось копировать видимые знаки, сохранять старые буквы ѣ, і, ѳ, ѵ и конечный ъ, не исправлять фамилии и не заменять историческое написание современным. Водяные знаки библиотеки не включали в распознанный текст; на сканах они сохранены.

Для PDF текст автоматически сопоставили с координатами на изображении. Отдельные сложные места проверили и исправили по сканам. Несколько страниц обработали другим способом: часть переписали по изображению, две страницы оглавления 1914 года распознали вспомогательным OCR и отметили для дополнительной проверки.

Flex — режим обработки запросов, а не отдельная модель. Сплошная ручная вычитка всех книг не проводилась.

Текст распознан с помощью ИИ и проверен выборочно. Возможны ошибки; важные сведения сверяйте со сканом.
